# Advanced AE！

Advanced AE 专注于改善 ME 系统的使用体验，并拓展终局系统的可能性。这个模组允许你升级样板供应器，使其能够将物品推送到目标机器的指定面；还可以创建能够在拥有合成存储空间时无限运行合成任务、共享协处理器的多方块计算机，此外还有大量其他便利性功能！
